## 开发逻辑与依据

### 统一目录与价格

`internal/modelcatalog/provider.Service` 取代 billing/provider 的旧 PricingService；app 新增目录构造和独立生命周期，价格和展示共用唯一运行实例。Wire 重新生成，移除旧 boot 目录维护重复挂载。后台更新、周期 ETag 检查、远程 304、本地补充/override 修改和离线启动共同走完整构建后发布；失败只记录错误，不替换可用快照。旧缓存不删除。

默认源变为 models.dev。已知公共 LiteLLM/Wei-Shaw 地址按 TokenFlux 规则在内存转换；管理员自定义地址不擅自替换，但必须返回新格式。旧 hash URL、按小时轮询、fork catalog_format 退役；旧 hash_check_interval_minutes 兼容到 check_interval_minutes。打包不再携带旧全量价格 JSON，缺失的已知旧资源路径映射到补充文件。

保留图片 1.5/2/2.5、GPT-6.1、Claude 5.5、Gemini 3.7/3.8 等 sub2api 增量，并将精确条目放入补充/静态价。补充按同一原厂记录身份扩展，不共享不同日期或中继价；图片缓存输入桶单独保存，不退回文本缓存价。显式 override 和价卡优先，已有账单/任务资金快照不重算。Grok 4.7 为明确注册型号，保留独立静态条目；不恢复任意 latest 别名兜底。

### 模型身份与协议

跟随 TokenFlux 的完整 ID：名字相近、日期版本或 -max 不能自动变为基础型号。计价、列表、管理测试、路由和能力读取使用相同完整身份；ByteSeek 额外分组白名单也去除旧 Claude thinking 隐式放行，保留明确通配符及协议 models/ 前缀解析。用户要保留公开别名时应配置显式映射；思考强度使用独立字段，不把后缀当字段。

GPT-6.1 的亚型校验由 protocol/openai 共享纯函数完成：最终映射后读取原始 body，防止 alias 绕过或转换吞掉 disabled。Messages→Responses、Chat→Responses、原生 Chat、Messages/Responses→Chat 均接入；只有 Chat-only 路线拒绝工具，Responses 工具不被误拦。显式 xhigh/max 原样保留；不恢复已退役后缀注入。OAuth/WS 共用归一化函数保留新 Sol 的 mode/effort，去除 sampling/logprobs，旧模型沿原逻辑。

Sonnet 5.5 工具 beta 的纯过滤移入 protocol/anthropic，Anthropic 出站继续通过旧包装处理大小写 Header，Vertex 在最终 beta 白名单后执行同一规则，避免平台之间互相导入。票据、质量检测、缓存身份和调度并未另造循环。

### 交互与定制

保留导航进度的旧包豪斯外观，只加导航编号与错误收尾。弹窗用 shared lifecycle 跟踪实际打开顺序，Esc 只响应顶层；快速关开、卸载和退出动画不会提前解除其它弹窗的锁，旧弹窗不抢新焦点。价格页只删除已退役操作，不重排布局。表格拖列、排行、黑色配置区和前版趋势能力保持。
