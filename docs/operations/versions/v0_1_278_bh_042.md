## 开发逻辑与依据

新增前端 `responseKindLabel` 白名单，仅影响日志拼接；服务端仍可保留 `other` 用于诊断和审计。IP 来源使用已有 `ip_source` 枚举，分别翻译，不新增请求。地区标签调用现有 `frontend/src/utils/ipGeoLookup.ts` 的 GeoJS 24小时缓存，只有已有参考 IP 才查询，并以 `[US]`、`[TW]` 形式显示；不把地区写入票据历史或接口。ChatGPT trace 的真实默认地址是 `https://chatgpt.com/cdn-cgi/trace`，失败后才按已有逻辑尝试 `https://api64.ipify.org?format=json`；两者均通过采集代理独立请求，不携带 OAuth/Cookie，也不代表采票连接的真实出口。
