## 需求与范围

修复旧首页翻译键裸露；两种皮肤使用同一原包豪斯首页结构，TokenFlux 使用其配色、圆角和轻阴影；恢复排行榜横条浅色填充。按完整 TokenFlux 功能＋ByteSeek 定制＋去重 sub2api 增量核查，适配本次新发现的六个 TokenFlux 提交。

## 功能变动

首页删除双模板，统一为原包豪斯构成；TokenFlux 使用局部品牌青、圆角、轻描边/轻阴影，包豪斯仍红黄蓝/硬阴影。标题和说明改为当前 multiProvider 键（稳定可靠/Always Reliable），示意 Key 品牌为 ByteSeek，LIVE ROUTE 显示当前精选/市场型号，不再固定旧 GPT-5.4。精选模型、统计、脚本生命周期、自定义 HTML/iframe 首页优先级、One Tap 和公共顶栏保持。

排行前三名横条恢复浅红/浅黄/浅蓝；小编号白底和大卡片红黄蓝/黑编号不变。主题仍由管理员配置，用户无皮肤入口。

TokenFlux 六项更新适配后，分组探针按请求模型选号、按分组映射结果执行测试，再由测试服务做提供商映射；候选列表按真实可请求规则产生。歧义裸型号属性可回退到一致的公共身份，不借价格。属性编辑添加精确模型且属性为空时自动填入，已输入或发生后续编辑则不覆盖。分布图按真实比例绘制，标签提高对比。

功能核查额外发现同版本导入不一致：前端接受 tokenrouter-data，后端却拒绝。现后端兼容该标识和原 sub2api-data，仍要求 version=2 和 proxies/providers；旧字段、错误版本、缺集合仍拒绝，本地导出标识不变。

## 开发逻辑与依据

multiAccount 旧键已被当前上游 multiProvider 替代；沿当前语义修正标题和说明，并使用真实中英文词典验收，避免 mock 返回 key 掩盖缺失。首页去掉双模板，皮肤只影响样式。排行榜保留大卡片和编号要求，小编号白底不代表整行白底。

HomeView.spec.ts 使用仓库真实中英文词典与同源编译器，逐个核对 HomeView 中的静态 t 键，并断言最终中文/英文、页面无裸 key、切换皮肤不重建主节点/不重复请求、自定义首页优先。测试环境的 runtime-only i18n 需要预编译词典，直接传字符串会返回 key，因此不能拿假 t 或无页面异常作为翻译验证。删除旧首页独有图标跑马灯变量与未使用函数，避免保留两套实现。

Template 结构共用，HomeView 内 scoped 规则只在 data-home-theme=tokenflux 生效；Tailwind 固定三原色工具类也做局部覆盖，避免只换 CSS 变量仍留下红黄块。换皮不触碰 API/数据。使用 color-mix 将排行榜名次色与当前表面色混合，深色同样保留层次，小编号白底单独控制。

上游改动按 T0→T1 补丁合并，保留现有中国平台、票据/质量和按键修复；ModelTagInput 空输入 Tab 可退出的本地修复保留。属性页补回适配 Teleport 的上游筛选测试，新增属性自动填充的过期请求保护测试；路由/目录测试保留本地默认价资料，不通过清空增量价格让测试通过。新上游未定价属性测试使用合成未知型号，避免与 ByteSeek 已登记 gpt-image-2.5-flare 的补充价冲突。

关键文件：HomeView.vue、HomeView.spec.ts、styles/bauhaus.css；gateway/provider/selection/probes.go → routing/group_probe_runner.go 与 group_admin*；app/routing_group_providers.go、routing_groups.go；modelcatalog/catalog.go 与 provider/catalog.go；ModelAttributesView.vue/ModelTagInput.vue；三个 DistributionChart 组件；provider/transfer/archive.go。删除只供旧对数压缩的 chartDisplayScale.ts 及其测试，遵循上游真实比例方案；历史代码可从 Git 恢复。
