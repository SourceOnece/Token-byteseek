## 开发逻辑与依据

1. 检查容器端口、Compose 展开配置与运行环境。原容器没有 8443 映射，Compose 环境与容器对应配置键无差异，健康状态为 healthy。
2. 只增加回环端口映射；Docker 修改发布端口需要重建容器，使用本地原镜像，禁止自动 pull/build，避免夹带升级。
3. 采集器本身仍由已有管理员 API 临时启停。CLI 使用临时 base URL 和临时 CA 信任，不能永久关闭证书验证；仅以真实 ClientHello 结果为成功，不以 CLI 完成模型回答为标准。
4. 采集不能经过 TLS 终止反代。采集结果不自动应用给任何账号。若缺少有效管理员凭据，停止采集操作，不重置密码、不伪造 JWT、不绕过后台认证。
