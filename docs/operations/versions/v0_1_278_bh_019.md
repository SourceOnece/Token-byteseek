## 开发逻辑与依据

镜像标签取应用交付的 fork 文档 ID 去掉开头 v，例如 v0.1.278-bh.018 对应 0.1.278-bh.018。先核对候选源码/版本/测试，再发布版本标签，核对清单 digest 后更新 latest、bauhaus；三个标签必须指向同一产物。已发布版本标签禁止覆盖为不同 digest，补推已存在同 digest 标签只作幂等核验。纯文档修订不占用应用标签，不修改应用 VERSION。
