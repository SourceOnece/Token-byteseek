## 开发逻辑与依据

质量检测结果为 failed 只能说明本次请求未成功完成，不能据此判定关键词未命中。服务与仓储区分“有效结果已接受”和“实际应用调度动作”，避免失败保存后被错误改成 stale。满血/降智仍使用原租约、配置快照/CAS、计划运行守卫及事务；失败不更新账号行或账号更新时间。被取消、配置变更、租约丢失、暂停或删除的在途结果不能绕过旧保护。

前端仅保存选定的七个表单字段；用版本化本地存储键隔离管理员，缓存损坏/字段非法时回退默认值，浏览器存储不可用不阻止检测。题目与关键词会留在本机浏览器，提示用户；不上传为全局设置，不跨设备同步，不缓存账号凭据。每次打开仍冻结本轮账号并要求重新确认。

关键路径：`CodexQualityTestModal.vue` → 管理员作用域本地配置；手动批次与定时 runner → `RunCodexQualityTest` → `FinishCodexQualityTest` → 最近结果/定时历史；仅 full/degraded 更新 accounts 和 scheduler outbox。
