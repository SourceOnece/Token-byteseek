## 需求与范围

按用户要求恢复双皮肤切换前的包豪斯首页，保留 TokenFlux 首页；移除头像菜单 GitHub 入口；包豪斯排行榜按红黄蓝排列，三个大卡片编号黑色，TokenFlux 不变。复核 TokenFlux 同步和包豪斯转化遗漏，提供近期功能、配置位置、未同步项及原因的通俗完整说明。

## 功能变动

包豪斯首页恢复不对称首屏、三元素轨道、品牌图标、黑带九词走马灯、数据方块、功能/精选模型/步骤卡片和 CTA，TokenFlux 首页保持原模板。共享 AppHeader，不恢复旧首页独立账户菜单；自定义 HTML/URL 首页仍优先。主题仍只由管理员设置，用户无切换入口。

排行榜包豪斯由上游 2/1/3 领奖台改为 1/2/3 顺排，红/黄/蓝，编号黑字白底、几何白色；下方榜单编号白底、指标依名次配色。TokenFlux 不变。头像菜单的内置 GitHub 地址与 SVG 移除，包括管理员菜单；原先普通用户本就不显示该管理员条目，本次彻底取消入口。

额外发现并修复 Select、BaseDialog 关闭、Pagination 和 FilterDropdown 的跨皮肤样式残留：TokenFlux 恢复其原样式，包豪斯在根属性限定下保留硬边/阴影/重点色。修复现行 UI 文档对缺失图标 README 的引用，把原始来源版本/许可信息并入规范。新增 [近期更新与配置说明](../recent_sync_and_configuration_guide.md)，不修改用户原有 bh026 比较文档。

## 开发逻辑与依据

首页参考包豪斯完整版本 7dd50f583，仅将 main/footer 呈现和必要装饰恢复到当前 HomeView 的包豪斯分支。脚本继续一份，市场 API、统计、精选模型、语言、公开配置、One Tap 和登录状态全部沿当前逻辑，切换皮肤不重复请求。普通主题模板保留，样式使用独立类名，避免走马灯动画串到 TokenFlux。动态轨道只展示唯一品牌，跑马灯每轮九词，第二轨道对辅助技术隐藏；减少动画时停止并换行显示单轮全部词。

旧 LIVE ROUTE 入场动画改为 backwards 填充，入场结束不再持续占用 transform，确保 hover/active 按压有效。顶栏继续当前公共实现，保留客服、余额、导航、明暗模式与菜单权限，不带回早期旧头部。恢复 CTA 的三角形，与圆和方形组成三元素。

排名数据、指标开关和请求不改；只增加稳定 rank/badge 类与属性供皮肤选择器应用。包豪斯排序由 CSS order 覆盖，上游 DOM/TokenFlux order 保持；编号独立黑色规则比大卡片白字规则更精确。浅色第二名列表指标使用较深黄以维持白底可读性。

Select 保留本地键盘焦点、候选变化、滚动定位修复，仅将默认样式恢复上游，原包豪斯差异归入 styles/bauhaus.css。BaseDialog 保留 showCloseButton 和退出生命周期；Pagination 保留数字输入 String 归一化；FilterDropdown 保留 Teleport、焦点、条件标签和 viewport 定位。没有为换肤覆盖这些功能。

关键文件：HomeView.vue（首页呈现/共用状态）、UsageRankingView.vue（排名稳定选择器）、styles/bauhaus.css（限定皮肤规则）、AppHeader.vue（仓库入口移除）、Select/BaseDialog/Pagination/FilterDropdown（默认控件对齐）；HomeView.spec.ts 验证共享请求、自定义首页优先及语言切换。AGENTS、设计/同步契约和 UI 规范记录用户本次授权的首页呈现例外，不把它扩展为其它页面恢复旧业务。
