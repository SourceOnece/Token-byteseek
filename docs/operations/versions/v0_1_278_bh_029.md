## 开发逻辑与依据

### 图片与安全

`usesCodexDirectImages` 先使用账号映射后的型号，再选 Codex 原生 `/images/generations` 或 `/images/edits`；原生 payload/解析器、后台探测与创作台执行器沿用 bh.026/bh.028。新增测试覆盖 1.5/2 生成以及三代原生编辑 SSE。旧 Responses 回归明确使用 Image 1；模型映射测试仍验证 Image 2→Image 1 的非恒等映射，默认请求仍为 Image 2，API Key 图片测试不被改成旧协议。

`forwardOpenAIImagesAPIKey → handleOpenAIImagesNonStreamingResponse → backfillOpenAIImagesB64JSON`：先从原响应提取 usage、数量和尺寸，再补交付字段，避免图片下载改变账单。账号 `extra.images_url_to_b64_json` 仅 OpenAI API Key 生效；默认关闭。明确 URL 格式、流式、已有 Base64 不补。每项最长 60 秒、最大 20 MiB，PNG/JPEG/WebP/GIF 字节嗅探；data URI 也校验。初始 URL 遵从出站配置，下载上下文强制公网地址；repository 对初始和每次重定向解析 IP，即便关闭全局 allowlist 也不允许私网。沿原账号代理，不附账号凭据，拒绝 URL userinfo 和 HTTPS 降级；错误日志不记录签名 URL。共享池客户端通过浅拷贝派生，不污染其它账号的重定向行为。

### 协议与号池

- Anthropic 文本按 output_index/content_index 保存已发内容，用 Builder 避免长回答反复全文复制。done 只追加前缀一致的缺失尾部；未知索引已有文本时不猜；终态恢复仅在完全无文本时执行。保留思考签名闭块逻辑、工具块和 usage，message_stop 后不再补发。
- Chat 工具 done 使用 Arguments/custom Input 对应字段；非流终态空参数以 Call ID 优先匹配，不能因数组重排串工具参数。Responses Lite additional_tools 只影响明确 namespace 声明；compact 和原账号摊平规则不变。
- Responses→Chat 角色规范化位于现有媒体/工具历史规范化之后，不覆盖本地 DeepSeek reasoning 回传等历史。该兼容取舍会把中途 developer/system 变为 user，内容位置不变，但角色优先级降低；这是明确的上游接口适配，不描述成语义完全不变。
- Claude beta 在最终请求头确定后清理对应正文。消息级 output_config 不影响顶层 effort；未知非文本块按真实内容保留。版本环境变量进程启动一次解析，四种 Compose 模板及 .env.example 透传，空值默认，非法/低于基线回退。
- HTTP→WS 客户端取消后用 WithoutCancel 读取已发出的上游结果，以原 WS read timeout 为排水总预算；保留 RequestID、图片、推理档位和风控字段。handler 断开分支只提交原有幂等用量，不进入换号重放、不向已关闭客户端追加错误。原生 WS 接入租约、TLS 硬兼容键及 Key/线程隔离不改。
- 本地池已拥有常驻读循环，因此对该桥的读取增加私有 drainable 标记：等待者取消不先 abort/evict 真实连接，才能继续消费队列里的终态；未带标记的旧消费者及真正 deadline 超时仍立即关闭。补充取消恰在阻塞读期间、常驻队列取消和 deadline 回收测试，避免只在直读 mock 下通过。
- 普通 OpenAI OAuth 图片保留 OpenAI profile 的 H1/H2 开关及代理回退，仅共用 H2 PING 10s/5s；API Key 长流 profile 在上下文读取及 TLS ALPN 投影完整保留，未声明 h2 的模板不强启 H2。
- Gemini 只新增观测：内容策略为 RequestScoped，不继承上次 attempt 错误或 skip_monitoring，不计入 provider SLA；Google error 与空响应按上游故障记。保留本地 SSE 的 reasoning/图片 parts 聚合、原结算、换号及质量检测门禁。

## 接口数据与兼容性

不新增 API 路径、认证类型、数据库 schema/迁移、依赖或应用 VERSION。新增账号 extra 布尔键及可选环境透传，不改存量账号设置；旧版忽略该开关。用户侧 Images 路径不变，上游协议按用户授权更新；原生输入输出/错误形状通过既有适配恢复。
