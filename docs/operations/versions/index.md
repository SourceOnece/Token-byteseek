# 版本历史目录

> 上级目录：[运维文档](../index.md)。编号和维护方式见[版本留档规则](../version_history.md)。本目录保存历史事实，当前约束见对应工程专题。

## 使用方式

每次开发先读最新交付及涉及模块的旧记录；同一上游版本的小修、文档变动也独立编号。目录从最新到最旧，源码/镜像/部署状态分别以记录正文为准。早于补录基线的历史尚未系统整理，不以猜测填充。

## 记录模板

- [版本文档模板](template.md)：开发逻辑、功能差异、验证和发布证据的统一结构。读取时机：每次新建版本记录前读取，不计入版本编号。
