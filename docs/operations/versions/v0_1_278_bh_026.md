## 功能变动

开发中，实际落地后补齐；预期减轻长会话重放内存、修复失败会话槽释放/续聊、按实际模型保留缓存身份、可热更新定价文件、记录上游 request ID，并接通 Codex 原生 Images 与现有工作台。
