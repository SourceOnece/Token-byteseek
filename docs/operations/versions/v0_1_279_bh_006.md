# v0.1.279-bh.006：使用密钥配置块改为黑色终端样式

## 元数据

2026-09-30 Asia/Taipei，代码与发布前验证完成，待发布。起点 `21dcd23a9`，前版 [bh.005](v0_1_279_bh_005.md)。应用 VERSION 仍为 0.1.279，发布修订 bh.006。

## 需求与范围

用户要求 API 密钥页“使用密钥”的可复制配置块使用终端黑底。只修改该弹窗的配置块，保持客户端选项、文件名、配置内容、复制事件及接口。

## 功能变动

浅色主题中原来的白色代码区和浅灰标题栏，改为深浅主题均固定黑底纸色字、深色标题栏、黄色文件名与复制按钮。复用原有 code-block 硬边/硬阴影，长文件名与手机代码内容保持可读。

## 开发逻辑与依据

[UseKeyModal.vue](../../../frontend/src/components/keys/UseKeyModal.vue) 仍用 `buildClientConfig` 生成 `files`，`copyContent(file.content, index)` 复制原文本。仅在外壳使用已有 `.code-block`（黑底 `#141414`、纸字 `#F4F0E6` 和主题硬阴影），标题深色 `#211f1a`、终端符号及文件名黄色，按钮复用 `btn-warning`。原始代码继续由 Vue 插值渲染；终端标识只是装饰，不进入剪贴板。不引入语法高亮依赖，不改变配置值。文件名窄屏截断并保留 title，复制按钮不被长文件名挤出；代码仍保持原来的自动换行和横向滚动能力。

## 上游同步与保留差异

非同步任务。TokenFlux 基线 `6d676f1d100e11f2f068949f5779e960c862079c`（v0.1.279），sub2api v0.2.10 `2f3fed2fdb0787141294cec81487a5df30426f7f`；两者业务同步范围与 bh.005 相同。

## 包豪斯适配

使用现有黑色代码块、纸色正文、包豪斯黄色标题/按钮、直角和共享硬阴影；标题栏的终端符号不增加交互步骤。

## 接口数据与迁移

不改 script、API、鉴权、配置生成、复制逻辑、数据库或迁移。只改变配置块外观及对应当前文档。
