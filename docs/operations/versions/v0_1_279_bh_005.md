## 开发逻辑与依据

生产代码只改 [CodexQualityDashboard.vue](../../../frontend/src/components/admin/provider/CodexQualityDashboard.vue) 的 `openAccounts`，以 `AdminProviders` 命名路由替代硬编码旧路径。`ProvidersView` 仍读取既有 `platform`/`quality_status`，`adminAPI.providers.list` 把参数交给 `/api/v1/admin/providers`；后台 `providerCustomFilters` 和质量仓储在 Count/分页之前筛选，实际验证正常，无需改动。

[导航回归测试](../../../frontend/src/components/admin/provider/__tests__/CodexQualityDashboard.spec.ts) 使用真实内存 Router 而非仅 mock `push`：原代码七种点击全部失败，修复后全部进入正确账号路由。满血率保留“全部 OpenAI 账号”语义，不误变为只显示满血；详情、检测和调度无变化。
