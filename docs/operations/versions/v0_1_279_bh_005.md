# v0.1.279-bh.005：修复满血统计跳转与账号筛选

## 元数据

2026-09-30 Asia/Taipei，代码、验证完成，待镜像发布。起点 `7ac2c68c1`，前版 [bh.004](v0_1_279_bh_004.md)；应用 VERSION 保持 0.1.279，修订 bh.005。

## 需求与范围

修复管理员仪表盘满血率、满血、降智、失败等统计无法进入账号管理和筛选的问题。保留包豪斯 UI、检测判定、票据、调度及既有接口。

## 功能变动

仪表盘统计原先仍指向旧 `/admin/accounts`，路由兜底后回到仪表盘；现改用命名路由 `AdminProviders`，并保留 `platform=openai` 与分类 `quality_status`。账号列表原有服务端筛选、刷新、分页和全选参数不变。

## 开发逻辑与依据

从统计点击事件经过 Vue Router、列表筛选、API 查询一直检查到数据库最近检测结果；使用隔离库及合成结果，不触碰真实账号或执行模型测试。

## 上游同步与保留差异

非上游同步。本地业务基线继续为 TokenFlux `6d676f1d100e11f2f068949f5779e960c862079c`（v0.1.279）及 sub2api v0.2.10 `2f3fed2fdb0787141294cec81487a5df30426f7f`；不引入上轮咨询中的新上游提交。

## 包豪斯适配

沿用现有统计卡、绿/红/黄状态、自研选择框、硬阴影和手机交互；本次不换皮肤。

## 接口数据与迁移

保持现有接口和参数；无数据库迁移。既有 `/admin/accounts/codex-quality-*` API 是已注册的兼容接口，不能因页面改名而一并删除。
