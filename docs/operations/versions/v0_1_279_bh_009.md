## 开发逻辑与依据

### 表格

`useTableColumnOrder` 以列 key 保存偏好，仅移动数据列，`select/actions` 是结构列。隐藏列的历史位置保留，新列追加；切换存储键重新读取，不把一个页面顺序用于另一个页面。存储损坏回到默认，存储禁用时页面内仍可移动。DataTable 表头、单元格及手机卡片共享 orderedColumns，排序仍按既有字段/服务端事件执行，不重排实际数据。

拖动手柄阻止点击冒泡，避免触发数据排序；宽表边缘自动横滚，松开或离开后清理动画帧。键盘左右移动后恢复同一手柄焦点。选择/操作列不显示拖柄，跨页 selectedKeys 和账号满血/邮箱等默认列序保持；只有用户操作后才改变显示顺序。手机使用已保存字段顺序，保留原卡片，不承诺手机触控拖列。

接入账号、用户、分组、代理、密钥、使用记录、审计、公告、兑换、订阅、团队、支付订单/套餐、推广、错误日志、图片任务、价格及模型属性等公共表格；UsageTable 为管理端/用户端分别透传不同的列存储键。已有定制复选框、质量/票据列和操作菜单不移除。

### 仪表盘

保留 UserDashboardStats、模型分布、绿色热力图、公告、快捷入口和页面布局；UserDashboardCharts 用 toolbar/trend 插槽接入上游查询状态和交互。新图表放在原趋势位置，复用包豪斯蓝及现有图表色板，不引入上游青色主题。

`usageChartState` 并发查询当前/上周期，序号丢弃旧结果；主查询失败显示错误/重试和“—”，不生成虚假的零消费。上一周期失败只隐藏环比。快捷范围按小时/天补空桶，自定义纯日期包含结束日；记住指标和快捷范围，敏感筛选值不存储。模型分布按同一窗口和条件查询，热力图及顶部今日/累计统计保持原口径。

候选来自现有个人 Key、团队 Key、可用分组及模型统计；个人 Key 读取所有分页，不止 100 个；团队不可用时保留个人候选。筛选弹层按现有定位 helper 挂载到 body，防止手机溢出和裁切，关闭后可回焦。图表遵循减少动画偏好；刷新仍同时刷新统计、趋势、热力图与公告。

### 其它交互

使用记录将表单“全部”与 API 未传条件区分，避免显示未选择占位；保留 0/false 的有效过滤意义。AppLayout 新增 fitViewport（保留原留白）和 hidePageHeading，原 fullViewport 行为不变。属性页复用现有标签组件，不因 Enter 提交整个表单；保存前拒绝空模型规则，关联组与显式 false 值保留。
