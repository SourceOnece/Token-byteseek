### 第二阶段：sub2api 协议与资格补差

桥接推理沿用本地 mapAnthropicEffortToResponsesForModel，不能覆盖为上游 max 一律 xhigh 的旧写法。新 GPT 判定复用本地整数安全解析，非数字家族不误命中。none 后禁止最终模型映射再次恢复 max。

工具 start input 暂存为 PendingToolInput，非空 delta 到达即清种子；stop 无 delta 才补发一次。关闭 item 清状态，确保不同工具间不串参数。空文本恢复只在不存在任何有效终态消息文字且有已观察 delta 时触发；不是凭空补内容或把失败标成功。

额度逻辑在 resolveOpenAIQuotaUtilization 与 openAIThresholdCandidate 同步使用未来 reset 判定；相对秒数继续锚定采样时间，不每次向后滑动。阈值仍由原配置决定，超出只收窄候选，不写总开关，不让合格票据绕过真额度不足。

Alpha Search 的 Responses 回退严格验证成功终态，再生成 WebSearchCalls 结果。协议测试的旧 JSON 夹具改为真实 SSE。Antigravity 在输出前缓冲结构帧，签名/stop 本身不视作回答，空流仍走原有有界重试/切号。PDF 仅透传已有 data URI，不新增外网下载。

## 包豪斯适配

新增白名单短提示与原 Toggle/textarea 共用，未引入原生 select 或新视觉体系。分页沿用方块、边框、黄色选中态；只放宽换行和页容量宽度。Ops 继续复用 BaseDialog 和原按钮。Usage 倒计时只修文字，正常/票据/检测颜色不变。首页、模型广场、三元素背景和硬阴影未替换。

## 接口数据与兼容性

无数据库迁移、表/字段重命名、公开 URL 变化、依赖升级或真实账号批量改写。白名单扩大可输入模式但不自动修改配置；原精确/前缀行为保留。回退旧版前，若已新建中间/前导 * 规则，须先换回旧版支持的精确/末尾 * 写法。请求 beta、思考关闭和文件桥接是明确记录的协议行为变化，不是仅 CSS。

票据采集参数、代理/TLS、缓存有效期、自动重采、调度三态及题目检测判定代码未改；共享协议路径改善可能影响转换后的内容完整性，故套件覆盖原票据和检测回归。配额暂停仍是额外门禁：票据合格开启 schedulable 不等于忽略额度不足。
