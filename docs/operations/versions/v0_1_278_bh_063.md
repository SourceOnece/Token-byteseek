## 需求与范围

用户要求“先适配认为应该适配的，再检查没有适配的”。本轮按既定去重契约先以 TokenRouter 当前架构为边界，再补 sub2api 0.2.9 的可独立修复。范围是：客户端主动取消的错误归类、OpenAI 透传账号的混合模型发现、Codex WebSocket 三条传输路径的上下文窗口切换，以及上游审计中发现的两个前端清理和两个部署/初始化安全小修。账号授权、模型路由、票据采集/注入、质量检测、调度联动、计费、会话隔离和包豪斯页面语义保持不变。

明确不做：不搬 TokenRouter 的 providers 重命名、原生 provider 模块、价格/媒体计费重构、破坏性迁移、全站圆角主题和 sub2api 自动重置权益。保留当前账号级长度信号、可选双链路和异常重采，不恢复已撤回的 Metadata 补齐实验。

## 功能变动

### 1. 客户端取消与真实上游故障分开

- Claude/Gemini 的通用 HTTP 入口及 Antigravity 补齐取消收尾；OpenAI 普通入口已有 499，本轮补 Alpha Search 和共享传输错误。取消兜底不再补写 502，纯取消不制造上游传输错误。
- 已经提交回答的流不追加错误帧；独立上游超时、连接拒绝、`DeadlineExceeded` 或已有上游错误仍保留原来的 Ops/账号健康证据。
- Google 形状把 499 映射成 `CANCELLED`。Ops 的 `IgnoreContextCanceled` 只跳过“纯取消”，取消前已经记录的上游失败仍然落库。

### 2. OpenAI 透传模型目录不再遮蔽普通账号

- 同一分组同时存在普通 OpenAI 账号和透传账号时，普通账号的显式别名继续展示，透传账号的旧 `model_mapping` 不会把废弃模型重新带回目录。
- 透传账号只补平台默认候选，最后仍经过现有白名单、分组允许列表、渠道限制、模型限流和账号资格过滤；因此目录变宽不等于放宽真实转发权限。
- 其它平台和非透传账号的模型解析保持原路径。

### 3. Codex 上下文窗口切换清理旧续链

- 从 `client_metadata.x-codex-window-id` 或 `x-codex-turn-metadata.window_id` 识别窗口；首次、相同或缺失 ID 不改变行为。
- 明确从窗口 A 切到 B 时，清除旧 `previous_response_id`、本连接的文字/工具回放、严格续聊状态和 HTTP bridge 工具状态；新窗口的第三轮仍可使用当前窗口的有效工具链。
- 覆盖原生 ingress、HTTP bridge 和 v2 passthrough。账号绑定、会话身份、业务代理和已经验证的 Codex STATE 不清除，避免把窗口边界误当成换号或重新采集。

### 4. 小范围上游审计修复

- 分组 RPM/倍率弹窗卸载时清理 document click 监听和待执行搜索，避免后台页面反复进入后监听器累积。
- 新安装配置不再写已经没有加载入口的全局 `rate_limit` 默认字段。
- 两套 Compose Redis 服务改为 exec 参数列表，密码按参数传入，保留 AOF、快照、内存上限和淘汰策略；密码为空仍启动无认证 Redis。

## 开发逻辑与依据

先核对 TokenRouter v0.1.279 在本 fork 中实际可复用的路由、模型目录和错误收尾边界；第一阶段沿用 bh.062 的采纳结果，B1=B0，没有新增原生模块迁移。第二阶段以此实际基线对照 sub2api 0.2.9，再加入下面六项差额。每项都保留本地调用关系：

1. 传输错误不记录为上游故障，需要请求 context 与传输错误同时可追溯到 `context.Canceled`；上游自己的超时/连接错误仍记录。handler 继续复用原 `failoverClientGone` 结束已经取消的入口（该旧函数也接受入口 context 到期）；并发超时仍走原 429/503 分类。没有修改原调度反馈评分或媒体断线后的用量排水。
2. 透传目录只修改候选收集阶段，不改 `Account.IsModelSupported`、实际账号选择、渠道/分组/限流过滤，防止为了修列表而改变放行资格。
3. 窗口 ID 在每个连接自己的 ingress 状态中比较。窗口改变只清理同连接回放状态；票据 STATE 保持按账号、模型、凭据和工作区隔离的原注入流程。没有窗口 ID 时 fail-open 到旧逻辑，兼容旧 CLI。
4. 前端和 Compose 修复均是资源生命周期/参数传递的局部变更，不扩展 API 或配置语义。

## 风险与后续同步保留点

- 取消请求在不同反向代理上可能没有及时传到 Go context；本版只在收到真实取消证据时归类 499，不承诺替代边缘层超时配置。
- WebSocket 客户端缺少窗口 ID 时沿旧续聊逻辑，旧 CLI 的服务端窗口切换无法凭空识别；带窗口 ID 的客户端不得跨账号复用连接状态。
- 透传目录补默认候选不等于上游授予模型权限；线上仍应核对分组、渠道和账号资格。
- Compose 参数列表避免 shell 展开，但部署者仍需通过 `.env`/密钥管理传入密码，不把密码写入仓库或日志。
- 后续同步不得覆盖票据 STATE 隔离、包豪斯组件、调度三态和本地迁移编号；TokenRouter 若后续带回同一 sub2api 补丁，应按本表去重。
