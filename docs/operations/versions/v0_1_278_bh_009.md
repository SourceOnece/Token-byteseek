## 开发逻辑与依据

[SettingsView.vue](../../../frontend/src/views/admin/SettingsView.vue) 的 userPromptReplacementTimezoneOptions 是两个动态替换类型共用的预设列表。后端早已使用 time.LoadLocation 校验 IANA 时区，因此只需增加 value/label 均为 Asia/Taipei 的选项。保持原列表项顺序、默认规则的 ID/scope/正则/捕获组以及可搜索/可自定义 Select 行为。

[SettingsView.spec.ts](../../../frontend/src/views/admin/__tests__/SettingsView.spec.ts) 验证两条默认规则均有新选项，初始值仍为 Asia/Tokyo，修改两条的目标值后原保存 API 提交 Asia/Taipei，刷新回显正确且规则其它字段不变。
