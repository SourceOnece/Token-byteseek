## 开发逻辑与依据

### 统一定价并保留已接入增量

`modelcatalog/provider.Service` 构建目录后，先用可选自定义补充填缺，再用内嵌补充填剩余缺口。目录明确的零价也算已有值，不被补充覆盖。计费核心只接收目录或价卡解析结果，移除 `fallback_data.go` 和按模型名猜价的运行时分支。未知型号缺价时保持未定价，不借其它型号的价格。

`CatalogRules` 保存媒体单价、Fast/Flex/Ultrafast、缓存写倍率和时段规则，校验后以独立快照发布。补充不再写旧 supports/max 等模型能力属性；展示属性由目录和管理配置负责。来源字段保留依据；ByteSeek 增量引用固定 sub2api 源码，不冒充本次查询供应商官网得到的新价格。

图片 1/mini/1.5/2/2.5 及日期型号的图片缓存桶、Sol 缺缓存写价时 1.25 倍/Fast 2 倍、Astra Ultrafast 6 倍、Grok 4.7、Gemini 3.7/3.8 的已登记档位迁入内嵌补充。只保留明确型号，不恢复任意后缀别名。Ultrafast 独立于 Fast，不被普通 Fast 覆盖。

图片缓存的字段存在性标志贯穿目录解析、运行时投影和计算：明确写 0 就按免费处理，只有缺失才沿原文本缓存兼容路径。测试覆盖非零、零和缺失；市场 DTO 同样区分图片规格缺失与显式零价。

按次区间、默认价格是否存在及媒体数量集中计算，报价/预占和最终消费不再根据模型名选择不同规则。资金事务、幂等与既有订单快照不重做。

### 功能接到原包豪斯组件

`FilterField` 向 `FilterDropdown` 登记条件及清除动作，自研 Select 报告选择结果。保留 body Teleport、弹层层级与视口夹取；点击内部 Select 传送浮层不误关外层。账号实际长度保留防抖和原参数，代理筛选仍回第一页。桌面按条件量排一至三列，窄屏单列。

日历功能沿用硬阴影、直角描边、黄色选中态和原按钮尺寸。新增 MotionTransition 只提供进入退出行为，不引入整套上游皮肤。

仪表盘保留原八统计卡片、左侧分布、右侧趋势、绿色热力图、公告及快捷入口。新增实时指标用原接口，隐藏页停止轮询，卸载后不写旧状态；分布复用趋势已取得的数据，减少重复请求。原错误重试和过时请求保护保持。深色选中卡片/模型行明确黄色底配深色字，避免全局卡片背景覆盖选中态。

## 接口数据与兼容性

- 本批无新数据库迁移，不改已发布 SQL，不清用户配置或账单。
- 鉴权、Chat/Responses/Messages/图片接口及调度入口保持；取价/结算确有变化，不能说业务完全不变。
- `pricing.override_file` 停用，非空时启动警告并忽略。依赖旧文件覆盖价格的部署者须在升级前迁到后台「价格管理」价卡，不会自动迁移。
- `pricing.fallback_file` 默认空，直接用内嵌补充。自定义文件仍可补缺，不能覆盖目录已有单价（包括 0）；操作价保留独立的内嵌默认/自定义逐字段叠加规则。
- 可选 `ultrafast_multiplier` 和图片缓存字段是本地兼容扩展，不新增用户 HTTP 开关。缺价不借任意硬编码型号，目录展示不代表账号权限。
- 镜像不再复制外置默认 JSON；旧资源可从历史 Git/前版镜像恢复，生产挂载数据和用户文件未删除。
- 统计接口、筛选参数语义保持，依赖变化为 axios 及锁文件。
