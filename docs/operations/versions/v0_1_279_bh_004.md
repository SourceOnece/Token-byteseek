## 需求与范围

用户反馈“使用密钥”弹窗生成的配置写着 `name = "TokenRouter"`、`model_provider = "tokenrouter"`、`"model": "tokenrouter/codex-auto-review"`，而站点是 ByteSeek，要求改成本站标识，“包括其他类似这种”，并重新打包。

范围：终端用户、API 调用方、付款人和管理员在本站实际可见、且写死为 TokenRouter 的品牌字符串。明确不改：Go 模块路径、浏览器存储键、加密派生种子、内部 Header/环境变量/临时文件名、指向上游真实资源的仓库/镜像链接（理由见[开发逻辑与依据](#开发逻辑与依据)）。不改变 API 路径、鉴权、计费、路由或数据结构。

## 开发逻辑与依据

**客户端配置**：`buildClientConfig` 原先把服务商 ID 和名称直接写在模板串里。新增导出常量 `CLIENT_PROVIDER_ID = 'byteseek'`、`CLIENT_PROVIDER_NAME = 'ByteSeek'`，Codex TOML 与 OpenCode JSON 共用，后续改名只有一处。ID 同时是 TOML 表名 `[model_providers.<id>]` 和 OpenCode 的“服务商/模型”前缀，所以必须保持小写 ASCII。

**为什么不跟随后台站点名**：站点名支持中英文分别配置并随界面语言切换，同一个 Key 会因语言不同生成不同的服务商 ID；中文站点名也不能直接作 TOML 键。用户已明确站点标识为 ByteSeek，因此固定常量，不从 `site_name` 推导。

**服务端 `owned_by`**：`httpapi` 包内新增 `siteModelOwner = "byteseek"`，`WriteCompositeModelsList` 与 `unifiedModels` 的未知别名兜底条目共用；OpenAI/Grok 目录已有 `OwnedBy` 的条目按原值透传，不被覆盖。

**其他字符串**：Stripe 仅改 `buildStripeCheckoutLineItems` 的空说明兜底；WebAuthn 只改 viper 默认值及示例配置，RP ID/Origins 不变；Live 相关只改提示与错误文案，判定逻辑不变。公开 Key 用量页删除 GitHub 链接及其 `githubUrl` 常量，页脚其余结构不动。

**明确保留**：

| 保留项 | 原因 |
| --- | --- |
| Go 模块路径 `github.com/TokenFlux/TokenRouter` | 构建内部标识，用户不可见；改动会波及全部 import 并放大上游同步冲突 |
| `tokenrouter:admin:*` 会话存储键、`tokenrouter-creative-studio` IndexedDB、`tokenrouter-auth-token-refresh` 锁、拖拽 MIME、图表 tooltip DOM id | 内部键；改名会丢失管理员草稿/创作室本地数据，滚动升级期间新旧标签页无法协调刷新 |
| `tokenrouter/live-attestation/v1` 加密派生种子、`DeriveStableUUIDv4` 种子、`tokenrouter.forwarded_ip_settings` 等设置键 | 改动会导致已加密数据无法解密、稳定 ID 变化或读不到已保存设置 |
| `TOKENROUTER_*` 环境变量、`X-TokenRouter-Internal-*` 内部 Header、临时文件前缀、TLS 采集 CA 名称/文件名 | 仅进程内或管理员工具使用，非站点对外品牌 |
| “Sub2API / TokenRouter”上游用量适配器标签 | 描述远端上游站点类型，本身是正确含义 |
| 版本检查/回滚命令的仓库与镜像、管理员头像菜单 GitHub、支付配置文档链接、`deploy/` 安装脚本 | 指向上游真实资源或仅管理员可见；本次不改变更新检查与部署工具行为 |

## 接口数据与兼容性

- API：`/v1/models` 本站兜底条目的 `owned_by` 值由 `tokenrouter`/`token-router` 变为 `byteseek`；字段、路径、结构不变。依赖该值做判断的第三方脚本需要同步。
- 已复制旧配置的用户：服务端不读取客户端本地的服务商 ID，旧的 `tokenrouter` 配置继续可用，无需强制更新。Codex 会在本地会话记录中保存 `model_provider`，改用新配置后，旧会话可能不出现在按服务商过滤的恢复列表中；不影响请求与计费。
- Passkey：显示名不参与凭据绑定（绑定依据是 RP ID），已注册 Passkey 不受影响。若生产 `config.yaml` 显式写了 `rp_display_name: "TokenRouter"`，默认值不生效，需另行修改部署配置（本次未改动线上配置）。
- 鉴权、计费、路由、数据库、迁移、依赖：无变化。
