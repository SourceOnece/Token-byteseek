## 开发逻辑与依据

### 有效配置与隔离

私有设置→总闸优先→账号规则/代理/守护覆盖→有效配置贯穿自动、手动、状态和门控，避免显示332但按全局292调度。旧账号未保存rules仍读旧全局默认，首次保存冻结完整有效规则，不重置用户已有模型/长度。账号变更只更新该号revision，全局保存仍使全局换代；账号revision与完整旧值数据库CAS防并发覆盖，跨实例每两秒轮询。旧任务不能把结果写为新配置的票。

### 有界无限与冷却

正整数：手动任务最多N次；自动每轮最多N次，之后周期仍可重试，保留旧行为。0：手动每次尝试后公平轮转，让出等待中的worker；自动每个短轮次一次，后续周期继续并累积次数。账号＋模型游标防尾部长期遗漏，扫描取有效账号最短检查间隔，旧全局长间隔不拖慢新规则。

尝试前先取得账号采集槽及原业务槽，再分配次数、调用取号API和探测；无槽不消耗取号流量。系统4worker、账号1–4槽（45秒租约）、原25秒探测/30秒自动轮次及8秒取号预算有界。Redis计数原子更新，成功票保存次数，下周期重置；孤儿计数24小时无活动过期，显式新手动批次重置。0不是无界并发，也不保证最终获票。401/403/429及明确认证/额度/参数拒绝保持保护退避和Retry-After，不能换IP绕过；0可等待退避后继续，关闭/取消/设置失联/丢锁仍停止。

连续采集不合格/失败按账号＋模型累计；排队无槽、取消、配置变化不算上游异常。达到阈值写独立冷却，暂拦该模型采集和票据门控，即使旧票尚有效；不写accounts.schedulable、质量标签或outbox。到期允许再采，成功清连续异常；不重新开启手工/题目检测停调。阈值0关闭此门控。自动/手动只在局部资格副本忽略schedulable，其它inactive/error/到期/限流保护保留。

### 代理与日志安全

固定选一条，轮换失败后下一条（最多20条），动态可每次展开显式认证SID或GET HTTPS取号接口。支持Mooproxy JSON proxies数组四段式、单条文本和完整HTTP/SOCKS5地址；无scheme按配置解释，本次实测服务选择HTTP。仅第一条，不执行返回内容，不将API地址当代理。端点/返回代理校验公网DNS并固定所选IP，不跟重定向；8秒/8KiB限制，不带OAuth/Cookie。取号URL加密且extraction_url审计脱敏，返回代理仅短期内存使用，错误不输出原URL/正文。

测试接口必须confirmed，只测试一条，不保存、不调用模型；复用ChatGPT trace/ipify参考查询及IP管理GeoJS地区缓存。每轮手动IP查询复用该次代理，不再次取号；独立连接仍不能证明上游请求同IP。手动total为各账号模型数之和，历史记录安全account_rules与模型并集，最终耗时覆盖等待和重试，不只最后一轮。

### 全池筛选与展示

ticket_filter在PostgreSQL Count/分页前执行，并传入全选/按筛选批量/导出。on只表示账号配置开启，不代表总闸/运行资格；未加入Redis实时ready/cooldown全池筛选。局部账号更新没有私有票据配置时等待重新同步，不凭普通DTO猜测移除行。状态只读且有界，次数/冷却不触发采集，票据结果不写质量检测结果。

## 风险与后续同步保留点

0无限可能持续消耗模型/代理配额并增加手动历史，务必通过停止/总闸管理。采集仍占原账号业务槽，可能减少可供业务的并发。每次重新取号不保证服务商每次返回不同IP；代理测试成功不证明特定模型可用，地区只是独立参考。

冷却有意让该模型暂不可调度，全池均缺有效票仍可能503；成功不重新打开手工/质量停调。成功票写入与冷却清理不是跨键事务，缓存故障可能短暂等冷却；设置有轮询窗口，不能承诺绝无竞争。账号规则映射/状态量随池规模增长，24小时孤儿计数不是永久审计，持久轮次应查看手动历史。

后续同步保留账号有效规则贯穿所有路径、批量勾选、0有界公平、采集与业务调度分离、保护退避、动态取号安全、密文/脱敏/模型凭据隔离、原生WS和满血绿。不能整文件覆盖恢复Metadata或把长度判断当模型质量保证。
