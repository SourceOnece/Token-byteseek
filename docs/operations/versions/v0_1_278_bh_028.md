## 需求与范围

用户要求接口、反代和模型能力优先采用 sub2api 方案，同时先梳理 TokenRouter 未同步项，再去重补 sub2api。Image 1.5、Image 2、Image 2.5 均明确改用 sub2api 原生 Images 接口。账号池调度、计费、订阅、质量检测、TLS、包豪斯 UI 和已撤回 Metadata/AT 实验不得被接口同步破坏。

## 本批同步分层

### 明确实施

- OAuth Codex Images：Image 1.5、Image 2、Image 2.5 及日期快照统一走原生 `/backend-api/codex/images/generations`、`/edits`；404/405 才回退 Responses。
- Responses/Chat/Anthropic 兼容桥：补完整文本尾部恢复、工具调用完成参数、namespace/additional_tools 等协议差额，保留当前接口形状。
- 长连接：HTTP/2 长流保活、客户端断开后有界排水、原有 WS 保活/隔离继续保留。
- OpenAI 429：区分真实额度耗尽与普通瞬时 429，避免误暂停整个账号。
- Gemini/Claude/GLM：补有明确测试和协议边界的终止信号、beta 字段和思考等级转换。
- 低风险接口改进：OpenCode 会话头、Gemini 自定义列表别名、Claude CLI 版本配置、API Key 图片 URL→base64 可选开关。

### 冲突项先适配，不直接覆盖

- Cloudflare Firefox 指纹：不能覆盖账号 TLS 指纹路由，只能限定 ChatGPT 后台检查客户端。
- 代理凭据指针更新：涉及 PATCH 的“省略/清空”语义，需同时改 DTO、前端、仓库和批量编辑。
- 连接池默认五倍扩容：不采用默认值，仅核对现有动态系数生效。
- Fast/Ultrafast、新收费倍率、OpenCode Go、MiniMax 等平台/运营变化：不混入接口补差批次。

### 已有或不重复同步

bh.026 已实现 WS 读循环/线程隔离、Codex 窗口修复、请求 ID、定价热加载、Images 2.5 原生路径及创作台 OAuth 分流；本批只补 Image 1.5/2 和后续差额，不重复旧补丁。

## 风险与后续

原生 Images 会改变 OAuth 上游响应形状，但对外仍恢复现有 Images 响应；旧 Responses 只作端点不可用时的回退。真实官方账号、额度和图片权限不在本地测试覆盖内。任何新增迁移或计费字段须重新记录并提高验证等级。

冲突清单保留待单独确认：代理凭据 PATCH 的“省略/清空”指针语义、Cloudflare Firefox 仅后台检查的指纹适配、连接池默认五倍扩容、Fast/Ultrafast 和 reasoning 计费、OpenCode Go/MiniMax 新平台、完整 pinned Codex manifest、CN/支付/代理运营大改。这些不会通过本批接口补差被隐式引入。

本次明确的图片目标是 Image 1.5、Image 2、Image 2.5 全部原生；旧 Image 1 仅保留 Responses 兼容回归。若旧测试夹具仍假定 Image 2 返回 Responses 事件，必须改为原生 JSON 或明确改用 Image 1，不能为了让旧测试通过而把生产路由退回旧方案。
