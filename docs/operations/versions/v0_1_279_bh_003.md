# v0.1.279-bh.003：恢复 ByteSeek 包豪斯视觉

## 元数据

2026-09-30 Asia/Taipei，代码、验证及镜像发布完成，未部署。起点 `ee58a5a90717e76f2f1b0417f27b32a0306fad51`，前版 [bh.002](v0_1_279_bh_002.md) 为部署留档。应用 VERSION 仍为 0.1.279，镜像修订号 bh.003；视觉参照迁移前已发布 bh.061/bh.063（`f0939293e`）及长期包豪斯契约。

## 需求与范围

用户反馈升级后多个页面丢失原包豪斯样式，要求遍历恢复，包括用量排行、按钮、表格、弹窗、菜单和深浅主题。当前接口、数据结构与业务行为不变。先完成本次视觉修复；其他平台上游功能同步是另批工作，不混入此视觉版本。

## 开发逻辑与依据

遍历当前 329 个 Vue 文件并比较迁移前后模板类名、局部 CSS 和全局样式；重点追踪原包豪斯选择器被留下、模板却已换名的情况。在现有规则定义处修正，不叠加一套宽泛 `!important` 补丁去覆盖全部按钮/阴影；标准 Tailwind shadow 已是硬阴影，只需移除深色清零规则。

新接口、组件输入与执行函数继续使用当前实现。除排行榜 render 函数的 class 字符串及图表颜色投影外，修改的 Vue script 区域未发生业务逻辑变化。纯图表颜色提取至 `constants/chartTheme.ts`，响应式主题读取常量，不额外触发 Chart.js 注册；原 `utils/chartTheme.ts` 注册顺序与默认值写法保留，避免重新引入登录时的 line/tension 初始化错误。
