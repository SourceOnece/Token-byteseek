## 需求与范围

用户要求批量修改同其它配置一样，先点勾选才能修改。范围仅 metadata 批量表单、测试、中英文说明和现行文档；不改其它批量字段、单账号开关、后端算法或收费。

## 功能变动

将三态下拉框改为“编辑该项”勾选框与独立开启/关闭 Toggle。默认未勾选，开关置灰且真正 disabled；勾选后才可操作，勾选且开关关闭提交 false，勾选且开启提交 true，取消勾选完全省略该字段。

## 开发逻辑与依据

`enableCodexMetadataRepair` 表示是否编辑，`codexMetadataRepairEnabled` 表示目标值；有效更新判断与 payload 构造共同检查编辑勾选和 OAuth/AT 资格。保留筛选范围变化、重开弹窗时的重置，取消勾选后即使目标值曾为 true 也不提交。控件复用公共 Toggle，并绑定 label、描述及 disabled，不能只用透明度模拟禁用。

- [批量表单](../../../frontend/src/components/account/BulkEditAccountModal.vue)：替换三态 Select，增加编辑勾选及独立布尔开关，更新有效字段判断、提交守卫与重置。
- [批量测试](../../../frontend/src/components/account/__tests__/BulkEditAccountModal.spec.ts)：修改原三态测试为勾选流程，增加取消勾选后旧 true 不提交、禁用状态点击无效等断言。
- [中文文案](../../../frontend/src/i18n/locales/zh/admin/accounts.ts)、[英文文案](../../../frontend/src/i18n/locales/en/admin/accounts.ts)：说明先勾选，移除仅被旧三态使用的三个文案键；单账号说明不变。
- [OpenAI 契约](../../interfaces/openai_upstream.md)：现行批量交互改为勾选编辑，不改后端字段含义。历史 bh.004 保留当时实现，由本版说明替代关系。
