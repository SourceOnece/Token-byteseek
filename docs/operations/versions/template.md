# 版本文档模板

复制本文的下列结构建立版本记录，标题改为实际文档 ID 和交付名；所有待填项在完成前替换为事实或“不涉及＋原因”。不把本模板本身标为发布版本。规则见[版本留档规则](../version_history.md)，索引见[版本历史目录](index.md)。

## 元数据

| 字段 | 内容 |
| --- | --- |
| 文档 ID / 日期（含时区） | 待填 |
| 类型 / 交付状态 | 待填：开发中、阻断、完成；测试/镜像/部署状态分别记录 |
| 前序记录 | 待填链接，首次基线说明原因 |
| 应用版本 / upstream SHA | 待填真实值，不因文档编号改 VERSION |
| fork 起点 / 实现提交定位 | 待填已知 SHA；包含本记录的提交可用 `git log -- <本文件>` 定位 |

## 需求与范围

待填：用户目标、原问题、允许改动和明确不改范围。

## 功能变动

| 来源与功能 | 变更前 | 变更后 | 受影响入口/角色 |
| --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 |

## 开发逻辑与依据

待填：最终方案、选择理由、关键调用/状态/数据路径、异常及回退、重要取舍。按本次功能完整说明，不能只列文件。

| 文件/符号 | 改动职责与关联证据 |
| --- | --- |
| 待填相对链接 | 待填关联调用方、测试或提交 |

## 上游同步与保留差异

待填：upstream/fork 起止 SHA、合并范围、冲突及解决理由、保留的本地行为；非同步任务说明上游基线未变。

## 包豪斯适配

待填：页面/公共组件、主题变量、语义重点色、硬阴影、三元素、交互和响应式状态；不涉及 UI 时说明原因和未改变既有契约。

## 接口数据与兼容性

待填：API、鉴权、计费/路由、数据结构、迁移编号映射、配置和依赖的实际变化或无影响依据。

## 验证记录

| 命令/操作 | 目标提交与环境 | 结果与覆盖 | 限制/未测项 |
| --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 |

## 发布部署与回退

待填：是否构建/推送/部署各自状态与原因，源码 SHA、应用版本、架构、两个 GHCR 标签及远端 digest、启动检查、旧版本和数据回退约束。纯文档明确不重打镜像；未执行生产验证不得写已上线。

## 风险与后续同步保留点

待填：尚存风险、未来同步不得覆盖的本地约束、后续工作以及相关旧/新版本链接。

## 追加证据与勘误

待填：没有追加则写“无”；每次补录注明日期、原因、证据来源，不覆盖原事实，不因此循环发版。
