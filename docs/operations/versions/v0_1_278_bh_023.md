## 需求与范围

用户要求保留旧 at-* PAT 加号方法，新增 ChatGPT Access Token + 空间/账号 ID 生成 AT 并直接入池，支持批量一行一个。发往 Wham 的 name 自动生成有用途含义的随机值，TTL 默认一个月按 30 天实现；能够通过既有 whoami 取得的邮箱保存至账号管理现有“账号邮箱”列。

只新增生成/导入路径，不改变已有 PAT 接口、调度算法、计费、缓存、模型协议、其他平台或数据库。名称用于凭据辨识，不实现“更像人工、绕过检测”的身份伪造；不会恢复被撤销的 Metadata 修复。

## 开发逻辑与依据

1. 初稿独立工具弹窗不能继承原表单配置，最终改为 OAuthAuthorizationFlow 的新授权选项与持续挂载插槽。CreateAccountModal.prepareCodexBearerImport 复用现有默认设置加载、模型白名单、Extra/TLS 选项构造器；旧 PAT handler 与 UI 事件保持原样。
2. 前端严格解析每一行，保留物理行号，拒绝无效/重复凭据对。不按空间 ID 合并，允许一个 workspace 内多个成员的不同 Bearer。请求前快照账号设置，逐条调用单条 API，每请求 90 秒等待；开始后清空文本框，结束/卸载清除令牌引用，不进入浏览器存储。
3. 后端新服务校验 Bearer/账号 ID/TTL（先检查整数防时间溢出），使用项目共享普通 HTTP Transport 与选择的代理，不跟随重定向。Wham 请求固定 URL、两项用户给定 scopes、Authorization、chatgpt-account-id、JSON 类型及 ByteSeek 项目 UA；不使用浏览器指纹模拟、不调用 privacyClientFactory、不自动重试生成。
4. 生成请求 30 秒、响应头 20 秒，生成及 whoami 合计 55 秒上限；响应读取上限 64 KiB。只识别明确 token 字段及约定容器，拒绝歧义、多 AT、非法过期时间。当前兼容字段为适配假设，尚无真实成功响应佐证，发布被此验证门禁暂停。
5. AT 复用旧 ValidateCodexPersonalAccessToken 校验，原 whoami 必填邮箱、账号/用户 ID、套餐、FedRAMP 不放宽。新服务和入库边界检查账号 ID 对应，凭据附加选项不能覆盖身份。BuildAccountCredentials 写 credentials.email，NormalizeOpenAIPersonalAccessTokenCredentials 不保留 RT/ID token 等 OAuth 刷新字段。
6. 新 handler 预检显式分组、代理、数值和 Header Override 后才生成 AT；随后调用既有 AdminService.CreateAccount，因此继承默认分组绑定、调度初始状态、过期暂停、模型/TLS 选项和原有创建后隐私动作。此次不改变这些公共函数。默认组变化、数据库/分组绑定故障仍可能发生于生成后，提示先查号池及上游凭据，不承诺事务或自动撤销。
7. 新 API 错误不回显 Wham 或 whoami 响应原文，标准 Account DTO 脱敏；审计包含 token 的字段已递归脱敏，无需改全局审计。网络错误、校验失败及入库不确定均不自动重试。
8. 另提供最多 10 项、1 MiB 的批量集成 endpoint，输入先全检，结果逐项隔离；客户端断开不再启动下一项。浏览器用单项 API 避免反向代理长超时，集成端需自行安排超时。

## 接口数据与兼容性

新增 POST /api/v1/admin/openai/create-from-chatgpt-bearer 及 /batch。身份字段 chatgpt_access_token、chatgpt_account_id，TTL 字段 ttl_seconds；其余为既有账号配置形态。单条返回标准脱敏 Account；批量返回 results、created、failed。不返回 Bearer 或 AT。上下游错误使用新 OPENAI_CODEX_AT_* / OPENAI_CHATGPT_* 码，与旧 PAT 不混用。

没有 schema、迁移、依赖、环境变量或应用 VERSION 变更。生成 AT 仍为 OpenAI OAuth 账号、PAT auth_mode，凭据不含 RT，不提供自动续期。账号 extra 新增 import_source 和 generated_credential_name 等非秘密来源标记；账号原 TLS 配置保留用于原支持的后续请求，Wham 本身只使用普通 HTTP + 代理，不能宣称其应用了 TLS Router 或“完整客户端伪装”。

## 风险与后续同步保留点

- 已使用用户授权的真实凭据测试 Wham，返回 401 phone_verification_required；未取得成功响应。字段兼容、workspace 权限及 TTL 上游接受范围仍不能据此确认，不能保证 AT 一定生成。

- 默认 30 天并非自动续期，账号过期继承原有暂停行为。
- 原始 Bearer 不落库，名称随机仅用于识别，不是“非机器人”或风控豁免保证。
- 未来同步不得把新方法覆盖进旧 PAT，不得恢复 Metadata 系列或改变号池已有调度/计费/指纹收敛。
