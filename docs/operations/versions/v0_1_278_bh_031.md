## 需求与范围

用户要求“添加账号”的 MiniMax、OpenCode 与其他平台选项保持一致，修正这两个选项独有的阴影和外观。仅调整平台按钮的类名；不改账号类型、模式、协议、导入、验证、接口、调度或计费。保留工作区之前未提交的升级说明，不将其混入本次改动。

## 功能变动

| 对象 | 变更前 | 变更后 |

| MiniMax / OpenCode 平台选项 | 使用 `.btn` 及 `.btn-secondary` / `.btn-primary`，未选中也有边框和硬阴影，选中为整块彩色 | 与 Kimi、Zhipu、DeepSeek 等平台使用相同分段选项结构；未选中灰字无独立硬阴影，选中实体底色、品牌文字和同源选中阴影 |

## 开发逻辑与依据

根因是同一平台选择区域混用了“提交操作按钮”和“分段选项”两种样式。按用户指定，以已存在的其他平台选项为参照；不改全局 `.btn`，不取消弹窗或其他业务按钮的硬阴影。两项同样使用高度 `h-9`、图文间距 `gap-2`、横向内边距 `px-4`；只有选中后才添加 `shadow-sm`，最终外观继续由全局包豪斯 CSS 规范化。
