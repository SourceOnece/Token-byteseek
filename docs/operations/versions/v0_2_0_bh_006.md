# v0.2.0-bh.006：移除首页 Token 总量展示

## 元数据

2026-10-01 Asia/Taipei，开发中。B0=63703bf2a，前序 [bh.005](v0_2_0_bh_005.md)。应用 VERSION 保持 0.2.0，交付编号 0.2.0-bh.006。未发布、未部署。

## 需求与范围

用户不需要首页“今日总 Token 量”和“历史总 Token 量”，两种主题及中英文均移除，不增加开关或仅用 CSS 隐藏。后台仪表盘、使用记录、计费和统计接口不在删除范围。

## 功能变动

首页统计区由四张卡片变为两张，仅保留总注册用户量和已接入模型，双列排列不留空位。清理两个 Token 卡片的动画状态、目标、无用格式化函数和首页专用文案；保留其它页面 Token 统计。

## 开发逻辑与依据

HomeView 共用模板和 homeStatsCards 只生成两个统计项目，HomeStatsKey/动画目标也只保留用户与模型。继续请求原统计接口读取总用户数，不改变服务端响应或其它消费者。剩余卡片使用明确装饰色，避免删除数组项后颜色意外变化。首页回归断言在双主题、中英文均无两项 Token 标签且只存在两张卡片。

## 上游同步与保留差异

本次不查询或同步新上游。TokenFlux 采用基线仍 7ac89a4658445cf6f20c82478ca7b66d17ca6378（Release v0.2.0=676b236919c2bf867d476497e3e9b89034004f5f）；sub2api 采用增量边界仍 42bc7f6cf，上次核查 d6adebd22（Release v0.2.11=96f4c115c）。首页省略 Token 总量是用户要求的展示差异，不是删掉 TokenFlux 统计功能。

## 包豪斯适配

同结构双皮肤继续生效；剩余统计保持原字体、动画、边框/阴影与各皮肤颜色，双列自适应。不影响三元素、走马灯和页面其它区块。

## 接口数据与兼容性

仅前端与文档，不改 API、后台字段、数据库、权限、计费、票据或调度。不是敏感数据屏蔽：原公开统计 API 仍返回原字段；用户要求的是首页取消展示。

## 验证记录

HomeView 定向 Vitest 6 项通过；TypeScript、Vite 构建、ESLint/UI token 与 diff 检查通过。两张统计卡在中英文、双主题下验证，今日/历史 Token 文案和 DOM key 均不存在。

## 发布部署与回退

验证后构建固定版本并同步 latest/bauhaus 同产物，不替换线上容器。回退 bh.005 恢复四张首页卡片，无数据迁移。

## 风险与后续同步保留点

同步上游首页时不能重新加入两个 Token 总量卡片，也不要因此删除统计接口或用户/管理员用量信息。完整发布证据后补。
