# Codex 可选票据

本文记录 bh.033 的 292 票据兼容边界，不等于官方能力保证或满血判定。只在管理员显式开启后运行，不恢复此前撤回的 Metadata/AT 实验；发布状态见版本记录。

<a id="ticket_contract"></a>
## 开关与存储

后台“系统设置 → 网关服务 → OpenAI”提供独立保存的可选设置；管理员 GET/PUT `/api/v1/admin/settings/codex-ticket`，缺省关闭。采集代理加密存入单独 settings 键，仅返回是否已配置；留空保留、显式 clear_proxy 清除。实例每两秒重读设置，本实例保存即时更新；读取失联超过十秒不继续采集/注入。每次保存更换代次，旧代次票据和在途结果不可复用。

票据 AES-GCM 加密后写入独立 Redis 前缀，最长一小时 TTL，不写账号 extra、updated_at、scheduler outbox、账号导出或普通 DTO。重启可在同一配置代次/凭据下读回 Redis；缓存故障保留原请求。代理密码在审计中整体脱敏。

## 探测和请求

只对独立、可调度 OpenAI OAuth 账号的 gpt-6-astra/gpt-5.6-sol 运行；不含影子、Agent Identity、API Key、其他平台及已停调账号。每分钟一轮、集群轮次租约、最多四个 worker、每轮三十秒、单探测二十五秒；账号/模型探测至少一分钟间隔，正常账号并发槽仍限制探测。关闭会取消在途轮次，已发出的请求不能保证不产生上游额度消耗。

探测发送固定 ping/pong 提示，仅读合格响应头；HTTP 200、292 字节、约定前缀和有效时间只作为兼容筛选，不证明模型质量。采集走单独代理和禁用重用的 H1 短连接，禁止重定向；不改变业务 TLS 指纹和账号代理。设置/凭据/工作区变动使缓存隔离键变化，不接收客户端写入的票据库。

出站 HTTP 与 WS 握手在最终模型确定后，只补缺失的 x-codex-turn-state；已有客户端会话状态优先，原跨账号来源剥离逻辑仍执行。缺票不拦调度，不现场探测、不重放业务请求。WS 只对新握手生效，关闭不主动切断已建立的业务连接。API Key/其他平台、未命中模型、关闭时均原样。

<a id="account_status"></a>
## 账号级只读状态（bh.034）

管理员 GET `/api/v1/admin/settings/codex-ticket/status?account_ids=1,2` 按当前页批量读取 Astra/Sol 状态，最多 100 个正整数账号 ID 一次、去重处理、整体两秒预算。只访问当前配置代次/凭据对应的 Redis 与账号数据，不刷新令牌、不触发探测。返回 enabled/server_time/items，逐号包含 eligible/collection_paused/models；模型状态仅有固定状态、原因码及检查/过期时间，不返回票据、token、工作区或代理。

有效性和剩余时间以原加密票据本身为准；独立 `status:` 观测记录最多保留 24 小时，仅包含固定状态/原因码及时间，不改变账号配置与调度。采集前后仅增加有界缓存观测写入（单次 150ms），不增加上游请求或调度写入。新版本可读 bh.033 已缓存的有效票；没有历史观测时不伪造采集时间。有效旧票优先于最近刷新失败，已消失的票据不因历史成功记录被显示为可用。采集中超过一分钟仍无终态视为待采集，过期按真实时间判断；缓存读取失败显示不可用，不伪装为采集失败或“降智”。

账号管理“满血测试”列在原结果下方分两行显示 Astra/Sol。有效为绿字倒计时、未获 292/过期为黄、采集失败红、采集中蓝、关闭/待采集/不支持/读取失败中性；原满血蓝/降智红/测试失败黄保持。独立 OAuth 才显示；API Key、影子和 Agent Identity 不显示票据块。当前页每十五秒只读轮询，原刷新按钮可主动读状态；每秒本地按服务端时间与单调时钟更新倒计时，不每秒请求。隐藏标签页不轮询，恢复时刷新；数据超过 45 秒不再信任其有效色。翻页取消旧请求、卸载清时钟；提示中的采集时间和原因只来自脱敏数据。

这里的“暂停采集”表示账号原本已不可调度，不是缺票导致停调；有效票也不代表账号可调度或模型满血。发布与未测项见 [bh.034](../operations/versions/v0_1_278_bh_034.md)。

## 与上游的区别

上游按账号/模型缓存并覆盖状态头，默认缺票阻止候选；本 fork 使用私有加密 Redis、凭据与配置代次隔离、限制并发且只补空头，缺票放行。依赖固定加密密钥和共享 Redis；不能保证不同真实上游会话的效果，需以少量账号验证后再扩大。不会自动变更 schedulable、满血检测结果、计费或订阅规则。

票据仍按上游账号/模型复用，不是按平台用户签发的新凭据。本地 Key/session/response 归属隔离保持原样，但无法证明上游不透明 turn-state 在不同真实会话间的全部语义；不能据单元测试承诺“绝不影响质量或缓存命中”。单账号连接测试、手动/定时质量检测的独立测试请求不注入此票据，本功能不将合成 ping 当作质量检测结果。合成采集只抬高 Astra 探测客户端版本到 0.153.4 下限，不回写业务客户端身份；不恢复旧 experimental beta。上游探测额度不记为某个用户的账单。
